Sizzle Street Kitchen is a fast little cooking game set in a busy street-food kitchen: orders land on the board, you stack each dish layer by layer on the assembly plate, grill patties and eggs until they sizzle done, and serve plates before customer patience runs out. Fast, accurate serves build combos and coins, wrong or expired orders cost points, and the lunch rush keeps getting busier until the shift timer ends.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
